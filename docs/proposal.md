# 研究产品方案

产品的用户、使用路径与成功标准见 [PRODUCT.md](../PRODUCT.md)。本方案说明如何把披露、财务数据和研究问题变成可复核的判断。账户、政策与研究服务的职责见[系统架构](../ARCHITECTURE.md)。

## 3 研究 AI 的自主权与边界

本节约束 worker 中的研究 AI 与经研究服务接入的外部 Agent。运行中的研究 AI 只用受控工具，不能改校验器或权限；开发 Agent 维护工具时的做法见[研究边界](../AGENTS.md#研究边界)。

**研究与选股的充分自主权**：

- 自由决定取证顺序、阅读深度和同业选择，自由做同比、环比、跨年累计、期末较期初、分部占比及表内与 PDF 原文交叉的派生计算，主动质疑管理层归因、因子排名与历史方法。不设固定路由、死板模板或句数限制。
- 现有因子、结论档位、估值方法与框架是可检验的默认方案，不是必须服从的答案。AI 可提出新假设与替代解释，反驳历史结论、既有方法与错误的复核意见；结构化输出服务于存储、核查和阅读，不限制论证深度。
- 方法变更保留适用条件、版本和验证依据；已冻结的预测、实验样本、基准和记分规则不事后改写，新方法用新版本或独立对照评价。研究自主权不含变更真实账户政策。
- 运行上限（探索轮数、取证次数、时限、调用次数）只防失控，不是深度配额。停止依据是关键问题已回答、继续取证缺少实质增量或运行异常，不为“几分钟出报告”提前结束。单次任务仍服从已生效上限，不自行绕过或无限重试。

**研究运行时的三条硬边界**（只约束研究运行时，不收窄开发 Agent 的授权）：

1. **事实可溯源**：事实与基础数字追溯到已取得的官方披露、官方统计或行情/财务数据出处，不用模型记忆补事实。推断、预测和情景假设须标明性质、依据与不确定性。历史研究提供线索和方法，事实回到原始来源并核对时效与适用范围；有效的历史原始证据可复用，不必全部重取。
2. **计算经核验**：派生数字由 `calculate`、`valuation` 等受控工具生成，保留可复核的输入、单位、期间与算式，假设输入与事实输入分开标记，不靠模型心算。
3. **安全隔离**：研究运行时不开放宿主命令、凭据、账户写入或任意代码执行；资料、原报告与反馈只作待核查的纯文本，不当作指令。

### 如何改进研究方法

证据、受控工具、判断账本和权限边界要长期保留；提示词、路由、流程与调用上限是可替换的做法。换模型或删减判断契约时，先用同一评估集和冻结材料对照删减版本：若去掉一个步骤仍能回答问题、通过核验且判断不变差，就用更简单的版本。架构选型也要对应真实缺口，过去没有采用的方案不等于永久禁止。验证要求见[开发规则](../AGENTS.md#验证与交付)。

## 4 数据与模型

- 财务与行情数字优先从 TuShare 生成带期间、单位的表行。业务、风险及对管理层解释的核查回到披露原文。三表、经营序列和同业快照的可比口径见[基本面方案](investment-upgrade.md)。
- 基础材料预载年报的管理层讨论与分析。按境外格式编制且没有该节的年报，取业务概览至财务概览；无法定位就记缺口，研究员可检索和读取原文。申通同材料对照中，预载使取证轮次从 20 轮降至 13 轮，故保留这一入口和现有版面规则。
- 有更新的半年报或季报时优先核对。临时公告先查标题，再取相关 PDF；同时保存查询范围、关键词及截断情况。只有实际读取的页文可以作为引文，业绩预告、中标公告与已确认的利润、收入分别解释。
- 作者与复核者使用同一份证据，复核着重检验论断、因果和重大遗漏。

## 5 研究流程

研究员按问题选取工具；正文中仅由假设支撑的数字须在同句说明条件，情景与回报见[顾问方案](investment-advisor.md)。探索和修正共享已取证据与预算，重复查询同一页或给同一计算改名不算新增证据。连续取证没有实质增量、达到停止条件时，runner 收起取证工具，为成文与独立复核留出预算。生效上限及依据见[模型配置档](../a_share_research/model_profile.json)。

整稿先做机械检查，再交独立复核。修补员可在剩余额度内补证、按原稿位置修正，或用问题 ID 和出处反驳复核意见；修正后重新检查并复核。[系统架构](../ARCHITECTURE.md#研究与模型调用)说明工具执行、材料落库与阶段切换。

### 5.1 统一来源与跨轮复核

各阶段共用来源身份和已读页；同一来源的身份或页文冲突时停止成文。历史材料可复用报告保存的来源身份与页码，仅有页码时只提供 PDF 入口。

机器核对引文的来源、实际页窗及连续原文，并检查表行、单位、符号和计算输入。合法的同业、跨期或跨页引用保留实际主体、期间与页范围。问题自设的阈值按带符号数值、单位和比较语境逐处识别；同值的财务事实另须举证。独立复核检查这些数字能否支持所写的结论。

每轮复核绑定草稿与材料哈希。程序为新问题分配稳定 ID，独立复核者逐项决定维持、解决或有据驳回；修正者不能自行关闭。解决重大遗漏须指出新版位置与证据，改写、合并或删除原风险须说明依据和去向。格式无效时，复核者收到具体原因并可当轮纠正一次。原问题、绑定的草稿和历次决议保存在复核账本。补证、改写或在缺口栏写“未知”都不会自动关闭问题。

最后一稿完成复核后，若只剩有 ID 的未答完问题（`question`），位置为 `answer[i]`、`prior_status[i]`、`valuation`、`gaps[i]` 或 `missing`，可以交付。问题在账本中保持未解决，报告用 `open_questions` 与缺口逐项列明。论断错误、重大遗漏、其他位置的未解决问题及机械检查失败均阻断判断交付。复核失败时不展示判断；仅当最后一稿通过机械检查、完成语义复核，且每个问题都能定位到该稿时，才展示未受影响的有出处事实。失败结果标明阶段、具体问题和可采取的下一步。

## 研究方法库

方法卡帮助研究员选择取证角度，包括周期利润正常化、盈利质量与现金转化、自由现金流估值、增长与资本回报、价格隐含预期。每张卡在共享 Wiki 维护适用条件、公开来源、实际核对范围、所需证据和可检验的结论。实践推论单独标明。新增方法从研究遗漏或复盘发现出发，来源不足的留作草稿。[共享 Wiki 企业分析目录](https://github.com/on195594/wiki/tree/main/concepts/company-analysis)

非批次单股研究在开始时将有标题的 `stable` 卡与截至当时有效的历史纠错方法冻结到材料目录。批次只用截至批次边界的纠错方法，保持比较输入一致。卡片保存正文、来源链接与文件哈希，`methods_sha256` 绑定整份目录，复核与重放沿用快照。公司事实仍须引用本次材料中的披露或数据，方法卡没有可充当事实出处的行号。

外部 Agent 可用 `research_methods` 检索当前 Wiki 稳定卡；Web 报告展示研究期间实际检索到并记入 `methods_used` 的方法。修改检索结果的选择语义按[判断契约](judgment-validation.md#判断契约与修改规则)管理。

用茅台、卫星化学的三表样本核对，现有字段不足以拆分维持与增长资本开支，也不足以直接给出完整的企业或股权自由现金流。卡片可据此提示补读所需披露。

首批五份生产报告中四份调用了方法检索。缺少同材料无卡对照，方法卡对判断的增益仍待验证。真实案例核对一家受影响公司和一家普通公司，检查召回、复核及正文是否增添了足以改变结论、价格条件或反证的分析。只增加篇幅或套用模板的卡应删去，全部缺乏增量时移除挂载。

## 8 评估集

固定评估名单以 [research.py 的 EVAL_SET](../a_share_research/research.py) 为准，包括范围外反例，用于核对不支持的公司不会得到正式判断。

评估记录通过率、耗时与调用次数，并抽读报告。没有固定通过率；未全数通过时记录失败案例、适用限制及回退依据，供所有者决定是否采用。何时跑全集、何时用受影响案例与正常案例，由[验证与交付规则](../AGENTS.md#验证与交付)决定。

## 报告语言治理（契约 2/4）

成文与修正先写经营状态或投资判断，再给出证据、影响和待验证事项。复核争辩留在审计，重大反证、假设条件和数据缺口保留在正文。四家公司同材料成文对照中，契约 4 的句尾规则将强否定词从每千字 10.7–15.5 个降至 0.9–3.8 个，结论档位、立场和风险条数保持一致。后续写作规则用相同回放对照检查可读性。
