# 候选发现与研究实验方案

更新：2026-10-24。状态：**方案已定、未实现**；阶段状态见[路线图](roadmap.md#3-本批与后续)和[实施计划](implementation-plan.md#工作包与状态)。

## 1 需求

2026-10-24 用户提出：“利用此工具选出近期 A 股投资回报最高的 5 支股票，当前系统无法解决。”确认的做法：

- 持有期 6–12 个月，以基本面与估值为主；
- 全市场确定性初筛 10–20 家 → 现有研究深挖 → 选 5 家进观察表；
- 不直接建仓，先做前瞻模拟（之后再做量化回测），作为策略演进依据。

系统不承诺“回报最高”，只给出按冻结规则和研究证据最值得观察的 5 家，并用对照组分别衡量初筛和深挖的贡献。

## 2 初筛规则 v1

初筛不调用模型。范围为沪深北 A 股普通股，每批标明实际覆盖的板块。数值是实验基线，正式批次运行时冻结，变更另记规则版本。

| 项目 | 规则 |
|---|---|
| 排除 | 金融类（研究流程暂不支持）、ST/*ST、退市整理、当日停牌 |
| 上市年限 | ≥3 年 |
| 规模与流动性 | 总市值 ≥100 亿元，近 20 个交易日日均成交额 ≥1 亿元 |
| 财务资格 | 最近 3 个完整年度扣非净利润均为正；最新年度审计意见为标准无保留 |
| 质量一 | 最近 3 个完整年度扣非 ROE（`roe_dt`）均值；Lib 现有 `roe_waa` 不是扣非口径；负权益记不适用 |
| 质量二 | 3 年合并经营现金流之和 ÷ 3 年合并净利润之和，分母须为正 |
| 成长 | `(末年扣非利润 / 三年前扣非利润)^(1/3) − 1`，需 4 个连续年度点且基期为正 |
| 估值 | 市值 ÷ 归母净利润 TTM；TTM 非正不参与“便宜”排名 |
| 动量 | 记录 60 日收益，跌幅 >30% 标出，不计分 |

行业内排名，首版固定申万一级，保存当批映射：

`总分 = 20%×扣非ROE分位 + 20%×现金含量分位 + 20%×成长分位 + 40%×低PE分位`

使用未舍入原值，并列取平均名次，可比组少于 10 家时标“样本不足”。缺数据的公司标出缺口，不当作淘汰理由。输出前 20 家（Q20），单一行业最多 3 家，每家展示原值、分位和缺口。

周期股在盈利高点会同时推高 ROE、增长并压低 PE，这由深挖检查。

## 3 深挖与冻结

Q20 中没有当期有效报告的公司提交现有研究任务，失败和被淘汰的也保留。全部完成后做一次跨公司比较（经 pi，记录在批次上，不挂到某个单股任务），给出 5 家草案，至少回答：

- 6–12 个月的回报来源是什么，是否都依赖同一行业景气；
- 是否存在周期高点低 PE、低基数增长、杠杆推高 ROE；
- 为什么不选机械排名更高的公司；
- 哪些证据会使判断失效。

用户在观察表确认并冻结，最终 5 家（L5）中同一行业最多 2 家，凑不满留空。持有中的股票由用户在确认时手动排除并注明原因。冻结后不再修改，改选另开新批次。

## 4 对照与前瞻模拟

每批保存三组，入场时点相同：

| 组 | 含义 | 用途 |
|---|---|---|
| Q20 | 初筛候选 | 初筛排序质量 |
| Q5 | Q20 按同样“单行业最多 2 家”直接取前 5 | 深挖增量的对照 |
| L5 | 深挖后最终 5 家 | 完整流程 |

另存进入行业排名池（U）的全部公司的因子原值，用于事后检查初筛。

模拟规则：

- 每月一个独立批次；6 个月为主评价期限，12 个月为次要期限，期限事后不换；
- 冻结后的下一个交易日开盘价入场，各组等权，持有期内不换股、不再平衡；空位记现金；
- 入场日停牌或涨停买不进的，该席位记现金；
- 用复权价计单位净值（分红视为再投资），扣固定双边费率 20bp；
- 基准：中证 800 全收益为主，沪深 300 全收益为辅（P0 确认指数代码）。

月度一批时，首批 6 个月结果约在 2027 年 4–5 月成熟。

## 5 历史回测（推迟）

对象只有确定性规则与 Q5/Q20，不评价模型深挖：用当前模型重新判断历史，会受到训练数据中“未来”的污染。

前瞻每批用当天数据并冻结快照，本身满足点时性；历史回测不行。现有取数按今天取最新版本（`sources.py` 用 `datetime.now`，修订版覆盖原版），历史行业、ST 和退市名单也是当前状态。开始回测前先做历史点时核查：

- 财务数据能否取到当时公开的原始版本；
- 股票池是否包含后来退市的公司；
- 行业映射、ST 和停牌状态能否按日期取得。

核查不过时，回测只作探索性分析。历史样本有限（10 年、6 个月持有约 20 个不重叠区间），回测用来发现规则的明显漏洞（如在周期顶部扎堆），不用来调参。

## 6 数据与工程

- 新增 1 张 `batches` 表：基准日、状态、规则配置，以及 U 快照、Q20、Q5、L5、冻结时间、入场快照（各存 JSON）。深挖沿用现有 `runs`/`reports`，批次只记关联的 `run_id`/`report_id`。
- worker 显式分派新任务类型（现有分派是 `price if … else research`）。
- 先用按交易日的全市场接口过滤行情类门槛，再对剩下的公司逐家取财务和审计意见，一次跑完，中断后重跑。账号没有财务批量（`*_vip`）权限，见第 7 节 P0 结果。
- 记录失败的端点、参数和错误，不把失败压成笼统错误码（旧系统的教训）；单家公司缺数据不阻断整组排名。
- 计算用原始数值，不用报告里两位小数的展示表。

## 7 分阶段

| 阶段 | 交付 | 验收 |
|---|---|---|
| P0 前瞻探针（半天） | 实测 TuShare 账号对所需批量接口的权限、截断与字段口径；确认扣非 ROE、合并口径字段和全收益指数代码 | 每个接口有真实返回或明确的失败原因 |
| P1 确定性初筛 | `batches` 表、初筛任务、U/Q20/Q5 快照 | 抽 2 家对照年报和行情手算 4 个因子与分位，结果一致；确定性测试；单股研究不受影响 |
| P2 深挖与观察表 | 关联研究、跨公司比较、冻结、观察表页面 | 本机用真实数据跑通一个完整批次；手机尺寸走通主流程 |
| P3 入场与净值 | 入场快照、三组与基准的单位净值对比 | 用真实入场日核对一次净值计算 |
| P4 历史回测 | 历史点时核查 → 规则回测 | 见第 5 节 |

P1–P3 是首版，目标 1–2 周跑出并冻结第一个真实批次；P4 在前瞻积累期间按需启动。

**P0 结果（2026-10-24，基准日 2026-10-23）**：

| 接口 | 结果 | 用法 |
|---|---|---|
| `stock_basic` | 上市 5577、退市 342 家 | 股票池、行业（金融类按 `industry` 银行/保险/证券/多元金融）、上市日期 |

## 8 首版不做，出现信号再加

| 不做 | 何时加 |
|---|---|
| 未复权股数与现金账本、最低佣金、分年度印花税 | 准备按固定本金实盘跟投，或复权因子明显失真 |
| 退市/长期停牌的情景估值、绩效更正流程 | 观察中真实出现停牌或退市 |
| 数据分片与中断续跑 | 单次初筛明显阻塞日常研究，或历史取数频繁中断 |
| 全市场原始响应入库、逐股淘汰明细表 | 需要跨批次对被淘汰公司做统计 |
| “筛选后立即入场”对照组 | 深挖与确认经常跨 2 个以上交易日 |
| 自动读取持仓做排除 | 持仓多到无法在 20 家里一眼认出 |
| 开发集/留出集、试验台账 | 不加：样本量不支持 |
