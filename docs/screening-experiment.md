# 候选发现与研究实验方案

更新：2026-10-24。状态：**需求已确认、待 P0 数据核查，未实现**。本文是初筛、观察表、前瞻模拟和量化回测的设计正文；阶段状态见[路线图](roadmap.md#3-本批与后续)和[实施计划](implementation-plan.md#工作包与状态)，职责见[项目契约](project-contract.md)。

## 1 需求与评价目标

2026-10-24 用户提出：“利用此工具选出近期 A 股投资回报最高的 5 支股票，当前系统无法解决。”随后确认：

| 项 | 用户选择 |
|---|---|
| 持有期 | 6–12 个月，以基本面与估值为主 |
| 产出 | 全市场初筛 10–20 家 → 现有研究深挖 → 选 5 家 |
| 用途 | 进研究观察表，做前瞻模拟和回测，作为策略演进依据；不直接建仓 |
| 排除规则 | 由 Claude 制定（第 3 节基线） |

“回报最高”不能由系统承诺。本能力回答“按冻结规则和研究证据，哪 5 家最值得进入模拟观察”，并分别评价三件事：

1. 初筛是否比基础股票池提供更好的候选；
2. 深挖与最终选择是否改善机械初筛结果；
3. 数据、研究和模拟记账是否可靠。

工程正确与策略有效分开验收：管线能正确运行即可交付工程能力，策略是否升级由投资证据决定。

方案经 Codex（gpt-6-astra，max）对抗审查后修订；v0 草案、审查提示与原文在 `~/.local/share/a-share-research-evaluations/screening-review-20261024/`（仓库外，0700），结论已并入本文。

## 2 时间与版本协议

策略演进依据最容易被三类问题污染：数据穿越、成交假设不可实现、事后挑选。每批保存：

| 记录 | 内容 |
|---|---|
| 策略身份 | 策略版本、全部参数、代码身份、行业体系与版本、计算口径 |
| 数据身份 | 请求参数、原始响应、来源、报告期、公开时间、取得时间、内容哈希 |
| 批次时间 | 行情日期、筛选冻结、研究完成、选择冻结、计划成交时间 |
| 完整范围 | 当时市场集合、逐股排除/缺失/不适用原因、原始因子、排名分母、候选名单 |
| 研究与选择 | 关联任务和报告、失败记录、模型与提示词身份、AI 初选、人工改选及原因 |
| 模拟执行 | 初始资金、目标权重、订单、成交/未成交、现金、费用、公司行动、估值和基准 |
| 后续更正 | 原因、旧值、新版本与生效批次；原始选择保留 |

- 前瞻批次的深挖可以使用筛选后新披露的信息，**收益从选择冻结后的下一个交易机会起算**。
- 历史回测只使用经验证在信号截止时已公开的数据版本。`ann_date` 过滤不足以排除事后修订：现有取数按“今天”取最新版本（`sources.py` 用 `datetime.now`，修订版覆盖原版），历史回测不能直接复用。
- 只有日期没有时刻的信息，按预先定义的保守可用时刻处理，不假定当天开盘前已知。
- 时间边界由取数工具和数据选择器执行，不靠提示模型“不要看未来”。

## 3 初筛规则基线 v1

初筛不调用模型：先枚举当时市场集合，再做范围、数据和规则判断。范围为沪深北 A 股普通股；每批标明各板块覆盖与缺口，未验证的板块公开标注，不把“全市场”悄悄缩成主板。

以下数值是**实验基线，待开发期验证**；正式批次运行时冻结，变更另记规则版本。

| 项目 | 规则 |
|---|---|
| 金融、ST、退市整理、停牌 | 按筛选时点状态排除；金融类因研究流程暂不支持 |
| 上市年限 | ≥3 年，独立参数；不代替数据完整性检查 |
| 规模与流动性 | 总市值 ≥100 亿元，近 20 个交易日日均成交额 ≥1 亿元；停牌日成交额计 0，缺失保持未知 |
| 财务资格 | 最近 3 个完整年度扣非净利润均为正；最新已公开年度审计意见为标准无保留；零值、缺失、非标意见分别记录 |
| 质量一 | 最近 3 个完整年度扣非 ROE 均值；先核对字段含义（Lib 现有 `roe_waa` 不是扣非 ROE），负权益记不适用 |
| 质量二 | 3 年合并经营现金流之和 ÷ 3 年合并净利润之和（同为合并口径），分母须为正，另展示逐年值 |
| 成长 | `(末年扣非利润 / 三年前扣非利润)^(1/3) − 1`，需 **4 个**连续年度点且基期为正 |
| 估值 | 同日市值 ÷ 截至该时点可用的归母净利润 TTM；TTM 非正不按“便宜”奖励 |
| 动量 | 保存 60 日收益与“跌幅 >30%”标记，暂不计分；记录它是否实际影响最终选择 |
| 已持有 | 不影响通用榜和对照组；“寻找新标的”视图另加带日期的个人排除层，保留过滤前结果。排除名单由用户或 Skills 经公开接口显式提供，Research 不读账户库 |

排名在行业内进行，首版固定申万一级并保存当时映射：

`总分 = 20%×扣非ROE分位 + 20%×现金含量分位 + 20%×成长分位 + 40%×低PE分位`

- 使用未舍入原值；并列取平均名次；可比组少于 10 家时标“样本不足”，不授予行业优胜含义（10 家为待验证参数）。
- 分位只是排序工具，不是预期收益或上涨概率；资料不足不解释为公司质量差，不当作淘汰理由。
- 输出前 20 家，单一行业最多 3 家；每家展示原值、期间、组规模、分位和缺口。
- 已知局限：周期股盈利高点会同时推高 ROE、增长并压低 PE，几个因子可能重复奖励同一种行业景气；这由深挖检查，并作为回测消融的首要对象。

## 4 深挖与最终五家

候选逐家提交现有研究服务，失败、未完成和被淘汰的对象全部保留。研究继续遵守现有事实、计算和工具权限边界，AI 可自主寻找反证。

单股“值得继续研究”不能自动映射为入选。最终选择是跨公司比较，至少回答：

- 在当前估值下，6–12 个月的回报来源是什么；
- 利润、现金、估值改善是否依赖同一行业景气；
- 是否存在周期高点低 PE、低基数增长、杠杆推高 ROE；
- 为什么选它，而不选机械排名更高的另一家；
- 哪些证据会使判断失效。

这是可复盘的问题，不限制报告形式或取证顺序。横向比较若调用模型，也经 pi 并记录批次身份，不伪造成某个单股任务。目标五家，不足时留空，不临时放宽条件；最终五家单行业最多 2 家。选择冻结后不再修改，改选记为新事件或新批次。

## 5 对照组与归因

| 对象 | 用途 |
|---|---|
| 基础池 U：当时符合范围和数据条件的全部股票 | 初筛的参照，同时保留全部缺口与排除 |
| 初筛候选 Q20（10–20 家） | 排序是否把较好对象推到前面 |
| 机械前五 Q5：按同样集中度约束直接取 | 深挖增量的主要对照 |
| 最终 L5 | 完整流程实验 |
| 未入选、未研究、研究失败对象 | 淘汰是否有效、失败是否造成选择偏差 |

主要比较：Q20 对 U（初筛）、L5 对 Q5（深挖，同资金、费用和入场规则）、L5 对预先指定的市场基准（完整流程）。另保留筛选后立即入场的机械基线，观察等待深挖期间的影响。这些比较支持增量分析，不等于随机实验意义上的因果证明。

## 6 观察表与前瞻模拟

推荐默认值（待用户确认，见第 9 节）：**每月一个独立批次**，固定初始资金独立持有，不拼成持续加仓的账户；6 个月为主评价期限，12 个月次要，3 个月只作过程观察。首版由显式提交启动，不自动新增定时任务。

执行规则在首批前冻结：

- 选择冻结后下一交易日开盘，按预定价格与滑点假设入场；五个席位各占初始资金 20%，交易单位和费用造成的余额、不足五家的空缺留作现金。
- 停牌、涨停买不进或行情无法确认时不虚构成交；首版只保留这一次入场机会。
- 持有期内不因表现换股或再平衡；到期卖不出时继续记录持仓和待退出状态，目标日估值和最终清算收益分开展示。
- 成交金额和股数用未复权价格，分红送转按公司行动处理现金和股数；复权序列只用于口径核对，不重复计入分红。
- 交易单位、涨跌停按板块和历史日期处理；退市或长期停牌不从样本消失，可回收、估值缺口和保守情景分别记录。
- 费用含适用印花税（按生效日期：2023-08-28 起卖出 0.5‰）、佣金及最低收费、其他规费和滑点，并列敏感性。
- 基准推荐中证 800 全收益为主、沪深 300 全收益为辅，指数代码与口径实现前核实；不用含分红的股票收益对比价格指数。
- 展示净收益、相对收益、回撤、现金占比、集中度、未成交情况，以及成熟批次数和重叠程度；独立批次收益不相加，也不拼成单一账户年化。

日线数据不能证明排队成交，结果标明为所选执行模型下的模拟。现有价格参考是研究材料，不是成交引擎。月度一批时，首批 6 个月结果约在 2027 年 4–5 月成熟；一次观察只证明流程完成一次，不证明策略有效。

## 7 历史回测

对象是确定性初筛规则及机械组合 Q5，Q20 用于候选质量诊断；**历史结果不标为“LLM 深挖策略收益”**。

区分三种“回放”：

| 类型 | 用途 | 首版 |
|---|---|---|
| 研究质量重放（现有 `--replay`） | 同材料比较研究质量 | 支持；不证明点时性或投资效果 |
| 已存前瞻决策的收益复算 | 前瞻批次到期后重算收益与归因 | 支持 |
| 用当前模型重新生成历史判断 | 模型可能见过之后的走势 | 仅作探索，除非能验证模型和全部取证链的时间边界 |

进入回测须先满足：点时的股票池（含后来退市的公司）、财务版本、行业映射与 ST/停牌状态；足够早的财务预热数据；与前瞻一致的成交、成本、公司行动和基准口径；用真实修订、行业变更、退市、停牌、分红案例核对通过。当前 `stock_basic.industry` 不用于历史行业排名。

试验纪律：先登记方案再算收益；开发期只做有限参数比较，留出期锁定，看过后不再称为未触碰验证；调参与验证窗口之间剔除跨越持有期的样本；记录全部因子、权重、阈值、行业、期限和基准尝试，主指标和主期限预先指定。

样本量有硬上限：10 年历史、6 个月持有只有约 20 个不重叠时间块（12 个月为 10 个），月度重叠窗口和五家公司都不能简单相乘为独立样本。不报精确胜率或显著性来制造把握；已被反复查看的历史无法恢复成未知数据，策略升级最终仍需新前瞻批次支持。

## 8 数据与工程

公共文档中的候选接口如下，**账号权限、积分、截断与历史版本保留均未实测**，由 P0 验证：

| 需求 | 接口 | P0 须验证 |
|---|---|---|
| 市场集合 | `stock_basic`（上市/退市状态与日期） | 历史集合完整性、代码变更、各板块覆盖 |
| 日行情与估值 | `daily`、`daily_basic` 按交易日全市场；Lib 已有 `fetch_daily_basic_by_trade_date` | 流控、单次行数截断、历史 `pe_ttm` 是否追溯修订 |
| 财务批量 | `fina_indicator_vip`、`income_vip`、`cashflow_vip` 按报告期 | 权限、字段、分页、原始版本是否保留 |
| 审计意见 | `fina_audit`（需股票代码） | 全市场批量成本与修订 |
| 预告、快报 | `forecast(_vip)`、`express(_vip)` | 首次与更正公告的区分 |
| 行业、ST | `index_member_all`（生效区间）、`stock_st`、`namechange` | 分类是否事后重分类、ST 完整性 |
| 成交与复权 | `suspend_d`、`stk_limit`、`adj_factor` | 历史覆盖、板块差异、公司行动核算一致 |

工程约束（沿用 [AGENTS.md](../AGENTS.md) 与[方案第 3 节](proposal.md#3-架构)）：

- 继续用现有 Python、SQLite、web/worker 和 pi；行情优先 Lib，Lib 没有的接口或字段在本项目直接调用 TuShare，凭据只在 worker。
- 新增实验批次、数据分片、候选选择、模拟事件和净值记录；单股研究继续用现有 `runs`/`reports`，批次只关联其 `run_id/report_id`。`reports` 保持“单股研究报告”含义，不用假股票代码承载批次。
- worker 显式分派新任务类型（现有分派是 `price if … else research`，新类型会误入研究分支）；全市场取数按交易日/报告期有界分片，分片之间允许处理日常研究。
- 中断保留已取得分片与诊断，显式重跑复用匹配分片；不扩展为通用恢复平台。
- 保留端点、参数、错误和覆盖情况，不把失败压成笼统错误码（旧系统 `FINANCIAL_FAILED_AFTER_TWO_ATTEMPTS` 的教训）；单股缺口不阻断整组排名，局部榜不标为全市场榜。
- 计算用原始数值，不用报告里两位小数的展示表；模拟记账是独立的确定性逻辑。
- 确定性测试使用真实采集样本；缺少真实异常样本时标未验证，不伪造行情或财务数据。页面走本机手机尺寸主流程；读取页面和 API 不触发取数或重算。

## 10 分阶段

| 阶段 | 交付 | 验收 | 停止/回退 |
|---|---|---|---|
| **P0 数据与口径核查（最先做）** | 字段—来源—时间—版本矩阵；有限真实取数探针；冻结的实验定义 | 真实修订、行业变化、退市、停牌与正常案例核对通过；账号权限、截断、覆盖明确 | 关键原始版本取不到 → 停止“可信历史回测”分支，继续前瞻 |
| P1 确定性初筛 | 完整市场枚举、逐股状态、候选榜与原始快照 | 同数据同规则结果一致；单位、期间、排名分母正确；缺口可解释；单股研究不受影响 | 权限失败、疑似截断未解决时不发布全市场榜，保留诊断和局部结果 |
| P2 深挖与观察表 | 10–20 家关联研究、横向比较、目标五家与全部淘汰记录 | 选择可追溯到冻结前证据；失败不伪装成通过；AI 与人工改选可区分；手机流程通过 | 证据穿越或未冻结的批次不计前瞻绩效 |
| P3 前瞻模拟记账 | Q5/L5 对照、虚拟成交、现金、费用、净值与基准 | 正常与真实异常案例核算一致；不可能的成交不会成交；重复更新幂等 | 计价错误时暂停发布该版本绩效，保留原事件并另出更正 |
| P4 历史量化回测 | 冻结规则的开发、留出结果与全部试验记录 | P0 历史门槛满足；股票池、行业、财务、成交、成本点时一致；窗口无标签跨界 | 版本缺口或幸存者偏差无法排除 → 降级为探索性分析，不发布有效性结论 |
| P5 策略版本演进 | 具体变更、归因证据、不确定性与下一批规则 | 增量证据来自规定对照和未用于调参的批次 | 无改善证据则保留基线；短期盈亏都不触发随意改规则 |

P2 与 P3 在首批称为“前瞻实验”前一起完成；P4 可与前瞻积累并行，不阻塞前瞻观察的启动。
