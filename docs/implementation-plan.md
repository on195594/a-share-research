## 当前部署

生产数据库为 **v25**，判断契约 **7**，生效政策激活记录 **30**。研究主模型为 `openai-codex / gpt-6.2-sol / medium`，复核为 `openai-codex / gpt-6.1-sol / high`。12-01 月批沿用此配置，11-18 主模型切换前后的报告分开记分。

回退须保留 v25 数据库、新账本和客户端状态。v24 镜像会拒绝 v25，迁移前的 v24 发布备份已轮替。故障时保留暂停标记，按[部署入口](../README.md#部署)核对实际镜像、读取兼容性和政策门禁，再用兼容镜像恢复或前向修复。使用本次发布批准范围以外的兼容镜像、新政策身份或备份恢复，须另获明确批准。回退到段 1 的 v25 镜像时，还须撤下 nginx 的 `/mcp` 路由并恢复对应的[宿主客户端备份](../ops/clients/README.md#段-2-切换回退)。备份恢复须保全新增写入。需要关闭 Web 账户写入时，撤销 `web-owner-proxy` grant #13。

## 待真实事件的验收

**12 月首跑最小验收（12-01 至 12-04）**

1. 核对 MCP 定时提交时间、实际回执、唯一批次 ID 和 `screen-v1.3` 快照。核对 Q20、S10 分池名单及每只候选的复用报告、新研究或失败记录。
2. 核对每项研究最多 21 次调用，三项比较或排序各最多 2 次，整批最多 636 次。标明缺失的调用用量。
3. 核对 L5、SL3 共同冻结时间和缺口，再查下一交易日共同入场、未成交现金席位、基准和首次收益。
4. 核对 Telegram 实际送达与去重，不另建批次。验收后清理本次月批核验提醒任务及脚本。

其余观察由真实事件触发，未给定截止日的项目不阻塞发布。

- **账户与调度**　核对 MCP 扫描、止损和 12-01 月度对比的首次自然执行。实盘触发止损或账户快照提醒时核对正文送达，盘中发布时观察止损暂停宽限与恢复。核对五宿主模型实际调用账户工具的结果及 AGY 登录。生产首次成功评估 NAV 区间时核对成功页和 H00906。所有者登录时核对 GitHub 登录与 30 天记住设备。
- **报告阅读与复核**　在真实手机及 Safari 上观察生产登录后的性能、读懂报告是否在两分钟内。抽查首批五份报告的 `open_questions` 有无漏过实质缺陷，检查契约 4 之后首批报告的否定词和复核修正轮数。按风险事件逐条核对首批接续报告的公告引用，统计 `unable` 和 `open` 比例。
- **数据缺口**　上游额度恢复后核对卖方覆盖窗口，待行情可用时复核监控评估标明的行业涨跌幅缺口。逐值公告映射、历史估值分位及波动指标、报告阅读后续与行业背景按[基本面升级方案](investment-upgrade.md)待确认。
