## 当前部署

生产数据库为 **v26**（11-23 由 `51b1c61` 发布，新增 `scheduled_runs`），判断契约 **12**（11-27 由 `7d7ea53` 发布，段 4b 知仓研究隔离、预告/快报事实锚点、PDF 续表单位作用域与市场比率口径提示；前驱契约 11 为 `e0e45dc` / `885b4ba`；`0de930c` 为段 4a 旧入口退役，不改库与契约）。模型只经 `agent-runner/` 调用，配置在[模型配置档](../a_share_research/model_profile.json)：作者 `openai-codex / gpt-6.2-sol / medium`，复核 `openai-codex / gpt-6.1-sol / high`。12-01 月批沿用此配置档，以契约 12 发起；允许复用 7 天内的契约 9–12 盲正式报告，不改写旧报告。11-18 主模型切换前后的报告分开记分。

生效政策以生产服务的只读查询 [`policy_current`](../a_share_research/tools/README.md#政策登记与切换) 为准。用[本宿主的客户端配置](../ops/clients/README.md#cli-与本机-cron)运行 `ashare --config <client.json> call policy_current`，读取 `activation.id`（当前编号）和 `installed`（实装身份是否一致）。核对某次发布时的状态则看该次 `release-state.json`。

回退按[部署入口](../README.md#回退)重新发布目标提交的镜像，通常保留 v26 数据库与新账本。回退至段 4a 之前（`f3c2372`）会恢复旧 `/api` 与 `/tools` 路由代码，但已撤销的旧 key #1、#3（`token_hash=NULL`）保持永久失效。**一旦库中写入过知仓记录（`holdings_context=1`），不能保留该库直接退回契约 11 旧镜像。** 保留该库时，回退版本必须同时保留知仓门禁与盲报告筛选条件；若要使用契约 11 旧镜像，须先恢复首次写入知仓记录之前的备份。发布工具只留当前与两级回退的镜像及最近三份发布前备份，实际可用项以 `docker images` 和 `DATA_DIR/backup-pre-*.db` 为准。

- **回到前一生产版本（契约 11，`e0e45dc`）**：不涉及库与政策；尚未写入知仓记录且在 11-29 冻结窗前可直接回退并重新确认月批基线，一旦写入知仓记录须先恢复首次写入前的备份。月批发起时冻结判断契约，此后切换到不同契约会让比较报错中止。回退也不会改变已有报告的契约版本。
- **回到更早版本（契约 10，`40dcec0`）**：须在 11-29 冻结窗口开始前且未写入知仓记录时执行。
- **越过定时任务状态段 3（`9651daf`）**：该段已删三个旧工具，只装回旧宿主脚本不可行。先按 [Hermes 手册](../ops/hermes/README.md#定时任务状态段-3-回退)交接未确认运行，再经固定入口重新发布 `9e77a07`（v26，旧工具仍在；工具按原参数自动激活其政策身份），最后在 `9e77a07` 上运行 `install.py --apply`。
- **越过 v26（`51b1c61` 之前）**：所需的发布前备份已按保留策略清理，只能前向修复。

需要关闭 Web 账户写入时，撤销 `web-owner-proxy` grant #13。`.env` 遗留的 `MODEL_*` 键新代码不读，所有者可删；无回退需要。
