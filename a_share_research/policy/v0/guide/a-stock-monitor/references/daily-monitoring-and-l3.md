# 日常监控、止损与 L3 核查

用于日常异动、公告、止损复查、活动预警及 L3 核查；动作优先级以监控快照与 [决策表](decision-table.json) 为准。

`research_thesis_review` 仅将干净快速路径的 `no_action` 升级为 `review_candidate`。保留快照中独立止损形成的 `trade_candidate`，沿用止损、预算与 L3 状态。列出待复核事件标题与类型，按[研究服务指南](research-service.md)核对原报告的公开证据，暂停解读该卡估值区间。

## 一、日常异常下跌核验

季报或重大公告期常规检索：`[股票] 最新公告 季报`、`[股票] 大股东减持`。

持仓股单日跌幅 ≥3% 或跑输行业指数 ≥2pts 时，当日检索 `[股票] 最新公告 异动 原因 减持 监管问询`，归类为：
- **已公告利空**
- **行业同步**（须基于同一交易日的板块/可比同业涨跌幅）
- **无公开原因**（注明截至查询时未见公告，并给出次日开盘前复核节点）

若当日缺少同日板块/同业对比数据，注明待次日开盘前补查归因。异动归因仅作事实说明，已触发的机械规则不得事后追加未预设例外，也不据此推翻已按快照触发的动作。

## 二、C 框架止损前置检查

C 框架持仓触发价格止损前，独立核查以下三项（每项取各自明确三态，缺数据标 `数据不足-待核实`）：

| 问题 | 可选状态 | 核查口径 |
|---|---|---|
| Q1：商品价格周期位置 | `底部区` / `非底部区` / `数据不足-待核实` | 核验商品周期证据；煤炭/金属引用现货价时注明长协占比及 1–2 季财报传导滞后 |
| Q2：公司整体盈利状态 | `已转负` / `未转负` / `数据不足-待核实` | 以公司合并净利润为准，区分单一品种亏损与整体转负 |
| Q3：核心 L3 逻辑状态 | `已证伪` / `未证伪` / `数据不足-待核实` | 核对结构化 L3 条件，区分基本面证伪与股价波动 |

判定规则：
- **周期底部保护成立**（须三项全部实证满足：`Q1=底部区` 且 `Q2=未转负` 且 `Q3=未证伪`）：第二档止损（快照 `stop_loss_20`）复查后的卖出幅度上限为减仓 50%，保留半仓观察反转。
- **正常止损**（`Q2=已转负` 或 `Q3=已证伪`，或执行节点前仍有项处于 `数据不足-待核实`）：按常规止损规则复查并决定减仓或清仓。
- 第一档止损（`stop_loss_15`）始终按常规执行完整复查。

## 三、止损机制

### 1. 论文破灭型止损（最高优先级，全框架适用）

仅两类情形可进入「已确认触发」：
1. 建仓/当前活动论文中结构化记录的某条 L3 数值条件达到阈值；
2. 确定性证据否定核心业务、监管可持续性或管理层诚信。

通用财务恶化（ROE 连续 2 季同比降 >5pts，或扣非归母净利润连续 2 季同比负增长）只触发「红色预警 + 框架专属复核」，用于区分增速放缓、盈利转负与竞争优势破坏。

状态路径：
- **结构化 L3 数值条件**：核实口径、报告期与计算无误后，标为 `triggered` 并输出该 L3 预设动作。
- **主观/事件条件**：`候选信号 → 待确认 → 已确认触发`——列明可查证事实、原始来源、对应 L3 与反证，间隔至少 1 个交易日复核确认。
- **通用财务恶化**：`红色预警 → 框架专属复核`；同时触发原始 L3 才升级为论文破灭，缺少可追溯 L3 时按“论文不可验证”处理。

输出 `triggered + reduce/exit` 前须确认该条 L3 契约有效：绑定当前活动论文且未退役、`scope`/`action` 合法、`materiality_basis` 与 `temporary_exit_rule` 完整、证据报告期匹配。其中：`non_core` 仅配 `review`；`governance + exit` 须有集团级确定性事实；`core_driver + exit` 须说明其为核心利润/现金流来源及确认期数；`aggregate + exit` 须基于集团或主要引擎的盈利、现金流或资产负债表指标。契约不完整时冻结交易建议并先重做论文。

**C/D 框架财务恶化专属复核**：
1. 独立核验周期/量价位置、盈利水平与原始 L3。
2. 若仍盈利、处于周期底部且 L3 未触发：维持红色预警并缩短至月度复核。
3. 若最近单季扣非转负，或核心量价驱动连续 2 报告期跌破 L3 线，或分红自由现金流覆盖率连续 2 报告期 <1：视为原始论文强证伪证据。
4. 保护仅针对通用财务恶化，已触发的个股 L3、监管或诚信事件照常执行。

### 2. P3 流动性休克门

仅适用于第二档止损（`stop_loss_20`）：全市场有效跌停数严格 >500 家时，沿用原预警延迟一次，24 小时内暂缓给出卖出股数。到期按原第二档止损价与当前可交易性复核：停牌或一字跌停记 `untradeable`，报价或可交易性证据不足记 `incomplete`。可交易时，价格回到原线上方则解除该档减仓候选，仍在原线及以下才形成减仓候选。

### 3. 基本面与价格止损

**基本面止损（配置型持仓优先）**：
- C 框架：商品逻辑根本破坏 → 考虑清仓；分红能力下修 >30% 且无回升迹象 → 触发复查。
- D 框架：股息率 vs 国债溢价跌破 100bps → 考虑减仓。
- 全框架：ROE 连续 2 季下滑 >3pts → 黄色预警；核心业务逻辑证伪 → 红色预警。

**价格止损（交易型持仓，C 框架先过前置检查）**：
- 直接使用本轮 `policy_monitor` 快照给出的 `stop_loss_15` / `stop_loss_20` 实际价位（按框架设定，非固定百分比）。
- 第一档（`stop_loss_15`）触发：按持仓框架完整复查基本面、估值与 L3（对应决策表 D05 `rerun_research`）。
- 第二档（`stop_loss_20`）触发且 P3 门禁确认可减仓时，目标减仓 50%，按交易所申报规则取最接近且不超过当前持仓的可执行股数；复查后决定是否清仓。
- 若宽止损框架持仓（如 F/C）的仓位占比与窄止损持仓相近或更高，在结论中提示“止损深度与仓位占比可能失衡”，供后续调仓评估。
- 明确区分**心理预警价**（触发 Step 2.5 L3 核查）与**止损执行价**（`stop_loss_20`），分两步表达；已触发的机械规则不得事后追加未预设例外。

## 四、活动预警核验

以快照与 `account_cycle_analysis_current` 中的稳定 `reason_code` 及 `active / pending / resolved` 生命周期为准：
- **黄色预警**（观察）：ROE 下滑 >3pts｜再融资摊薄｜核心高管离职｜机构持续减仓。
- **红色预警**（复查/考虑减仓）：2 项以上 `holding_deterioration` 黄色预警同时生效｜商誉减值｜大股东减持。（`entry_valuation`、`unverified` 单独展示，不计入恶化累计门槛。）

每次核查逐项确认：证据是否仍成立、是否到 `review_due`；已消除或需续期时列出 `account_cycle_analysis_update` 拟议变更等待确认，证据不足则保持 `pending`。

## 五、步骤 2.5：L3 主动检查

季报后或重大行业变化时按 `evidence_cadence` 主动核查：
- 季报裁定 `quarterly` / `event` 行；`semiannual` / `annual` 行仅作检查点保持原状态；`unspecified` 行先由用户确认分类再裁定。
- 读取当前状态与历史使用 `account_cycle_analysis_current` / `account_cycle_analysis_history`。
- 财务核对使用 Research 报告与程序财务表（`T.roe`、`T.core_profit`、`T.op_cash`、`T.capex`、`T.fcf`）。加权 ROE 为期间累计口径，不用两期累计值相减冒充单季 ROE，也不将中期数据机械年化；资产负债表同比以去年同一期末（`yoy_same_period_end`）为主，较年初（`vs_year_start`）标注为季节性对照；所有派生指标均由程序工具计算或取自已复核财务表。缺少程序口径时标为待核实。

核查步骤：
1. 检索 `[股票] 季报 最新 行业动态 竞争格局`。
2. 核查当前活动论文的**全部** L3 条件，逐条记录状态、依据与来源日期。单期可查指标先查当期数据；确认触发或未触发分别记 `triggered` 或 `not_triggered`。已核实需观察的条件记 `watch`，冻结该股新增风险；条件更接近触发边缘时升级黄色预警，缩短复查周期。证据不足记 `pending`（待核实），列明缺项与下次核实节点。
3. 若 L3 记录仅引用了缺失文本的历史版本，视为“L3 尚未核查”，不得直接给出“继续持有”等清洁结论：先从周期分析历史或原始存档恢复并标注原始来源；无法找回时明确标为“本次新设监控条件（非建仓原始论文）”，同时列出待补全条件、下次验证节点与临时出场框架。
4. 按证据频率列出待确认的 `account_cycle_analysis_update`（`kind: "l3"`）变更。

**等财报时的判断树**：若建议等待中报/季报/经营数据，同时给出覆盖至少 2 项关键 L3 的判断树（`达标 → 加仓/持有；跌破或恶化 → 减仓/止损；中间区间 → 维持并于 N 日内复查`）；无法设定阈值时说明原因。首批与后续加仓按[风险预算定仓](portfolio-risk.md#五基准仓定仓板块权限与治理红线)执行，披露未达标时复核是否减仓。
