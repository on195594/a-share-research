## 组合风险前置检查

`risk_budget_exceeded` 升级时只读使用当前 `monitor-v1` 快照，不再运行下列命令：
`code=null` 是组合级，其他 code 是单股级；只复核已给出的金额、比例、限额和分母来源。
不重复取持仓或报价、不调用 W1、不展开全组合研究。风险合计为 null 时只可引用明确命名的
`known_stop_risk_lower_bound`，已有超限不能被其他持仓的未知风险抹掉，缺项不由模型心算补齐。

独立请求组合风险（尚无本轮快照）时，默认读取系统已存的“可投资组合总资产”——股票市值 + 本策略可动用现金，不含房产、应急金。只有不存在可用存值或范围冲突时才补问，不每次索要截图：

```bash
$CACHE portfolio-risk
```

本次用户显式覆盖时再附 `--portfolio-value <总资产>`。本次及存储都没有总资产时，只能用已取价股票市值作临时分母，可以监控但不判定预算超限，也不得授权加仓。部分持仓缺少有效行情时，仓位只能标为“已取价股票仓位（下限）”。

不在示例命令中覆盖个人预算；只有用户明确指定本次覆盖值时才附风险限额参数。有个人政策文件时，使用已存截图明确且匹配的账户范围，或本次明确的 `--account-scope <账户范围>`；本轮使用显式 `--policy-file` 时沿用该路径。不要单独附 `--portfolio-value-as-of` 为旧存值补新时点；仅显式提供 `--portfolio-value` 时附同源已确认的 `--account-scope` 和可选 `--portfolio-value-as-of`。本次及存储都缺范围才请求补充，不从政策文件反推用户确认，不删除政策或退回默认绕过报错。

### 有效政策与分母证据

两个风险入口使用同一解析结果。政策路径优先级为本次 `--policy-file` → 环境或
runtime.env 的 `A_STOCK_RISK_POLICY_FILE` → 配置目录 `risk-policy.json`；只读已有文件，
不得自动创建或确认。文件须用户所有且权限 0600 或更严格，生效、有确认元数据并与
本次 `--account-scope` 或已存截图明确的账户范围一致。显式覆盖值 > 有效文件 > 兼容默认；非法、未确认、
未生效、过期或范围冲突的已选文件，即使有数值覆盖也不回退。

`--portfolio-value-as-of` 记录用户给出的资产估值时点，不是报告采集时间。
缺少时点或范围时 `denominator_requires_review=true`，仅可观察，新增风险须复核。
不设置自动 TTL；有 as-of 也不自动证明新鲜或授予交易权限。止损距离估计、已发生
回撤与可选 `drawdown_observation_target_pct` 分开，不承诺回撤上限，不默认写入 5%。

### 风险预算

`单股当前净值回撤贡献 = 股数 × max(现价 − 第二档止损价, 0) ÷ 可投资组合总资产`

该指标衡量“若从当前市价持有到第二档止损线，当前组合净值可能回撤多少”，包含尚未
实现的浮盈回吐；它不是买入本金亏损，也不是现价距离止损线的“安全垫”。现价上涨会
增加等待至同一止损线时可能回吐的当前净值，不能据此把公式反向解释为风险下降。

- 默认单股上限2%、组合第二档止损风险合计上限8%；均为待回放验证的启发式默认值，
  用户有既定预算时以用户值为准；
- 任一单股或组合严格 `>` 上限才超限，不按显示舍入值判定。超限冻结新增风险建议，不自动卖出、不调整止损；
- 兼容默认 `compatibility_default` 并非已确认个人政策；显式 CLI 覆盖须显示真实来源，模型不得为绕过超限自行调整参数；
- 针对高权益仓位（如股票仓位 > 70%）或持有大幅浮盈标的的组合，兼容默认 8% 易触发常态化超限。用户可通过 `--policy-file` 或在 `~/.config/a-stock-agent/risk-policy.json`（权限 0600，user-owned）中配置个人预算。不在示例命令中覆盖个人预算。
- 政策文件可选字段 `off_account_strategy_cash`：仍归本策略、但在券商账户外的现金，只能由用户确认写入。
  有 `--portfolio-value` 时分母 = 账户资产 + 该值，输出 `denominator_components`；资金转回账户时须同步改文件，避免重复计入。
- 超限明细的 `principal`/`unrealized_gain` 是第二档止损风险中本金与浮盈回吐的拆分；报告超限原因时只引用这两项和
  `denominator_components`。超限只触发复核：快照未给出的卖出标的、顺序或股数不得提出，也不得仅因浮盈占比高建议先卖盈利仓。
- 冻结建议不阻断用户确认的已成交事实记账，仍需原 W1/具体动作授权；记录后报告异常，禁止拒记或改写真实成交；
- 已跌破第二档的持仓单独标为“已破线”，不能因剩余风险为0显示正常。

### 用户指定数量的只读情景

仅当用户明确要求假设计算并指定股票与卖出股数时，使用已有完整 `monitor-v1` 快照文件：

```bash
a-stock-cache portfolio-scenario --snapshot <仓库外快照JSON> --sell <代码>:<股数> --fees <含税总费用估计> [--cash <同一时点已确认现金>]
```

多只股票重复 `--sell`，同一代码不得重复。缺股数/费用只询问缺项，不自行选股、定量或假定免费；没有可用快照仍按主流程请求账户资料。不得修改快照填补账本差异；已知用户持仓与快照冲突时停止并先对账。

结果只代表 `snapshot_as_of` 时点的静态假设，不代表今日交易可执行。按输出展示前后股票占比、止损风险、预算状态、现金增量及费用；未提供现金则现金总额未知，不从“资产减市值”推算。卖出所得转现金、资产只扣费用，不重复计入收益。保留原复核缺口；即使预算改善，也不清除 L3/财务门禁或改变原账户建议。`action_status=not_formed`、`execution_status=not_checked`：未核验 T+1、交易单位、滑点、可卖数量；不得把结果当交易候选。命令不取新价、不写库、不下单。

### 券商成本与规则参考成本对账门

券商截图成本、`holdings.cost_price` 与 `holdings.reference_cost` 口径不同：券商成本只
用于复原截图账户盈亏；经济回报按不可变交易事件现金流计算；Tier 与框架止损使用
`reference_cost`。三者数值不同不自动证明任一方错误，也不得据此直接覆盖本地账本。

当券商截图成本与本地记录不一致时：

1. 先核对4项基本要素：券商持仓数量 vs `holdings.shares`、券商市价 vs `quote.price`、券商成本 vs `holdings.reference_cost`、券商浮盈 vs 账面计算；
2. 核对买卖事件、费用税费、现金分红及除权送转记录（券商摊薄成本通常扣除累计分红，导致显著低于建仓成本）；
3. 未完成对账前，成本比例派生的止损/Tier只可展示来源，不得授权对应交易；
4. 结构化L3中的绝对价格线仅在确认其与当前除权口径一致后才可执行，否则保持待核实；
5. 成本复核须分别注明账户盈亏成本来源、规则参考成本来源及对账状态。

### 集中度

- B银行+D公用事业/水电市值占股票总市值≥60%：置顶风格集中提醒；
- 第一大仓或单股权重≥25%：以①②③编号输出止损来源、L3逐条状态、估值退出距离；
  缺任一项列为复核缺口，加仓限为首批，不整体否决持有或加仓；权重本身不是上限，规模只受
  风险预算约束（见下节）；
- `portfolio-risk` 使用 `holdings.framework/framework_confident` 并按市值汇总。框架为
  `?` 时停止框架动作；需要变更时用 `holding-framework` 显式迁移并重算止损。

### 闲置资金与风险预算定仓（[2026-11-04 规格](https://github.com/on195594/a-stock-agent-skills/blob/master/docs/specs/2026-11-04-proactive-decision-spec.md)）

- 未部署的股票资金默认持中证 800 ETF 515800（汇添富中证800ETF）作为基准仓，而不是现金。该仓不计单股止损、L3、单股风险预算与集中度；个股买入所需资金先卖它。买卖建议仍由所有者确认后执行（W1）。
- 新仓或加仓的规模只取只读命令：

  ```bash
  a-stock-cache position-size --snapshot <仓库外快照JSON> --code <代码> --price <拟买入价> --framework <A-F> [--cash <可动用资金，含可卖出的基准ETF>]
  ```

  输出 `max_shares` 与 `tranches`（1/3、2/3、1 三阶段累计股数，不足一手的阶段为 0；首批恒为 `tranches[0]`）：股数 ×（买价 − 第二档止损）同时不超过单股剩余预算与组合剩余预算，并按板块交易单位取整。`budget_below_one_lot` 如实说明，不换别的上限。现在分批带 `add_trigger` 或旧等证据带 `trigger` 时，动作只限 `tranches[0]`，检查点参考不阻止首批；不得将 `max_shares` 当成当前可买股数，也不得反复以首批名义追加。披露达标且更新有效研究确认后才加后续批次，未达标复核是否减仓。结果 `action_status=not_formed`、`execution_status=not_checked`，不核验涨跌停、滑点与可成交量。
- 账户板块权限：风险政策可选字段 `untradable_boards`（`STAR`/`BSE`）所列板块照常研究，但不出机会提示、不作换仓候选、`position-size` 拒绝定仓；未提供账户范围时也生效，被排除代码写入 `research.reason`（[2026-11-04 板块权限规格](https://github.com/on195594/a-stock-agent-skills/blob/master/docs/specs/2026-11-04-untradable-boards-spec.md)）。

### 组合复盘与换仓比较

- 用户要求组合复盘或换仓比较时，从 `research.opportunity_costs` 取全部达标比较（不受 7 日时效限制），结合 `research.holdings/candidates` 给一张表：区间、保守/中性/乐观年化回报、卡片状态、收盘日、风险占用。持仓风险只引用本轮 `holdings[].stop_risk/stop_risk_pct`；候选未给风险占用则标未知，不假设买入数量补算。行带 `assumption` 时在表下原样注明（回报按 Research 假设测算，非已核实的换仓回报差）；待复核卡保留区间和回报，但注明“区间暂停解读”；null 保留未知，不当零。

### 行为与宏观检查

- 总账浮盈首次由负转正时提示一次：不得因“回本”改变L3或估值纪律；
- 宏观变量必须写成
  `变量 → 传导路径 → 持仓 → 正/负/中性 → 操作影响`；
- 以“纯内需/无敞口”排除汇率、出口或海外资产路径前，必须核实最新财报中与该路径
  直接对应的收入、订单、外币资产负债或境外子公司数据。
