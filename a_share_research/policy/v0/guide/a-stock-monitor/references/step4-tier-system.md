## 步骤4：分批止盈规则（A/E/F框架，配置型B/D框架用步骤3估值信号出场）

### 通用定义

**"1/3仓位"全局定义**：经送转等比例调整后的 `initial_shares` 的三分之一，是目标
比例而非委托股数。每次必须用 `sell-holding` 校验可申报数量；沪市500股整手持仓
不得拆成167/167/166，可采用200/100/剩余200等最接近目标的可执行路径，并记录偏差。

**Tier触发必须严格按1→2→3顺序**。论文破灭型止损不受此顺序约束；结构化L3
触发时直接输出其预设动作和可申报股数，不需要补齐未执行Tier。

### Tier 1：共享第一档（A/E/F框架统一）

```
触发：当前价 >= 建仓成本 × 1.25
操作：卖出 1/3 建仓量（纯收益锁定，优先级高于估值信号）
```

⚠️ **+25%是尚未完成历史回放的启发式阈值，不是已证实最优规则。** 当前保留它作为
预先承诺基线，所有触发与未触发案例都进入回放数据；不得在报告中称其为经验证策略。
成本锚使用 `holdings.reference_cost`，经济收益仍用交易事件现金流计算。

| 资格 | +25%触发时条件 | 动作 | Tier1状态 |
|---|---|---|---|
| 非E/F框架，或轻仓试探持仓，或无有效建仓日豁免声明 | 任意 | 卖出1/3建仓量 | 完成 |
| E框架正式仓位 + 有效豁免声明 | 按下方口径计算的当次PEG `<1.5` | 不卖出 | 已触发并按预设条件豁免（视为Tier1完成，可继续核查Tier2） |
| F框架正式仓位 + 有效豁免声明 | 当次PS低于近5年40%分位 **且** 收入增速未跌破15% | 不卖出 | 同上 |
| 有效豁免声明但上述条件不满足，或PEG不可计算/数据口径无法确认 | 不满足/不可计算 | 卖出1/3建仓量 | 完成 |

**豁免资格与声明规则**：正式仓位须在建仓当日通过
`tier-config <代码> none none E|F` 写入 `holding_tier_state`。命令会校验声明日期和
`holdings.framework`；事后声明会被拒绝。轻仓路径日后升级不构成建仓时正式仓位。

**判定与记录**：数据须当次取得并保留来源、as-of和数值；Tier1豁免时执行
`tier-update <代码> tier1 exempted`。Tier2不追补豁免份额。

### 轻仓试探专属出场规则

当矩阵建议仓位为「轻仓试探」时，必须在建仓当日通过 `tier-config` 选定路径：

| 路径 | 触发条件 | 操作 |
|------|---------|------|
| **路径A — 升级为正式仓位**（首选） | 季报/中报确认 L3 全部未触发 + 时机评级升至 ★★★ | 加仓至 1/3 仓，此后转用标准 Tier 1/2/3 规则出场 |
| **路径B — 个人止盈目标**（需建仓时预设） | 到达结构化 Tier 配置中的目标涨幅 | 全部卖出，用 `sell-holding ... all` 记录成交 |
| **路径C — 标准 Tier 1**（缺省） | 当前价 ≥ 成本 × 1.25 | 等同正式仓位，执行清仓（轻仓试探无需分批） |

**使用说明**：
- 示例：`tier-config <代码> B 10 none`
- 未配置路径时不得自动假定路径C；先补全结构化配置，避免旧持仓被静默套用新规则
- 路径B的止盈目标须在建仓时基于技术位或基本面预判设定，不得以"刚好回本"或"心理价位"为由设定
- **论文破灭型止损优先级始终最高**（见步骤2状态机）；只有结构化 L3 已确认触发，或监管/诚信事件经确定性证据否定投资论文并完成状态机确认后，才输出预设退出建议。普通“重大利空”标题只进入候选→待确认复核，不直接授权清仓

### Tier 2/3：按框架分别定义（A/E/F框架适用）

> ⚠️ Tier 1/2/3 目标价必须以 `holdings.reference_cost` 动态计算，不可使用硬编码值；
> 实际总回报使用交易事件中的买卖现金流、费用、税费和分红计算。
> 当前持仓查询：`a-stock-cache holdings --active-only`

⚠️ **E/F框架的Tier 2/3数值为本次新增，按A框架已有的"Tier2略低于步骤3卖出阈值、Tier3等于步骤3卖出阈值"这一相对结构类推得出，不是历史回测校准值**——使用中如发现明显不适用（过早/过晚触发），应作为独立复盘项提出调整，不要求当前用户逐一确认才能使用（当前无更好依据，先建立可执行规则，后续可修）。

⚠️ **PEG的增长率（G）口径必须固定为以下可复算公式，禁止临时切换**：设最近已披露完整会计年度为`t`，`NP0=NP_t`，`NP2=NP_{t+2}`（第二个未来完整会计年度归母净利润的机构一致预期）。按`G_pct=100×[(NP2/NP0)^(1/2)-1]`计算**百分数形式**的两年复合增速，再按`PEG=PE_TTM/G_pct`计算PEG；PE_TTM与一致预期须使用同一as-of日期。数据源名称、as-of日期、NP0、NP2、`G_pct`及PEG计算结果须记录在notes中。若NP0≤0、NP2≤0或无法取得同一数据源的NP2一致预期，本次PEG记为"不可计算"，按步骤3「⚠️ 评估任何估值卖出信号前...」的要求处理，不得改用其他临时口径。

补充口径：这里的 `PE_TTM` 必须是真正的滚动十二个月市盈率，不能把缓存中按最新年报 EPS 计算的静态 `pe_ttm` 字段冒充 TTM。若只能取得静态 PE，PEG 记为"不可计算"并按步骤3要求处理。

若无机构一致预期数据，可使用以下预先定义的fallback（不得与上述主口径混用择优）：取最近已披露完整会计年度`t`与三年前完整会计年度`t-3`的扣非归母净利润，按`G_pct=100×[(NP_t/NP_{t-3})^(1/3)-1]`计算；两个端点均须大于0，并记录年度、数值及来源。同一持仓一经采用某一口径，后续核查不得更改，除非原口径客观上已无法取得，且须在notes说明变更原因。此口径同时适用于本节Tier1豁免的PEG判定、下方Tier1后补仓规则的PEG判定，以及步骤4以外任何引用同一PEG机制的场景，三处不得使用不同口径。

⚠️ **E/F框架Tier2/3触发前须核对数据时效性和计算正确性，不得以主观理由改判触发状态**：触发第二档或第三档前，须确认所用PEG/PS/收入增速数据来自当次实时刷新（而非历史缓存），并复核数据源、报告期、公式和单位。若核查后发现确系缓存过期、字段误取或计算错误，应以更正后的数据重新计算——这属于纠正数据错误，不属于规则例外。真实披露的经营数据（包括一次性因素导致的波动）仍按订正后的数值正常判定是否触发，不得以"非经常性""短期扰动"等未预先量化的理由，在数值已达标后临时改判为"未触发"。

**A框架 Tier 2/3 模板（PE分位触发）**：
```
第二档（兑现收益）——以下任一满足即触发，卖出 1/3 建仓量：
  方式A：当前价 >= 成本 × 1.50 AND PE_TTM >= 近5年60%分位
  方式B：PE_TTM >= 近5年75%分位 AND 净利润增速最近2季度转平或转负

第三档（兜底清仓）——以下满足即触发，卖出剩余持仓：
  PE_TTM >= 近5年85%分位（与步骤3 A通用卖出信号一致）
```

**E框架 Tier 2/3 模板（PEG触发，类推自A框架相对结构）**：
```
第二档（兑现收益）——以下任一满足即触发，卖出 1/3 建仓量：
  方式A：当前价 >= 成本 × 1.50 AND PEG >= 1.5
  方式B：PEG >= 1.8 AND 净利润增速最近2季度转平或转负

第三档（兜底清仓）——以下满足即触发，卖出剩余持仓：
  PEG>2（与步骤3 E消费卖出信号"PEG>2"逐字一致，不用">="避免恰好等于2时两处判定不一致）
```

**F框架 Tier 2/3 模板（PS分位+收入增速触发，类推自A框架相对结构）**：
```
第二档（兑现收益）——以下任一满足即触发，卖出 1/3 建仓量：
  方式A：当前价 >= 成本 × 1.50 AND PS >= 近5年65%分位
  方式B：PS >= 近5年75%分位 AND 收入增速最近2季度跌破20%

第三档（兜底清仓）——以下满足即触发，卖出剩余持仓：
  PS超近5年80%分位 且 收入增速跌破15%（与步骤3 F科技卖出信号严格一致的措辞，含"超"而非"≥"）
```

注：论文破灭型止损不属于以上任一框架的 Tier 系统，其触发绕过 Tier 顺序、独立执行（见步骤4「通用定义」中的例外说明），不应理解为"必须先到 Tier 3 阶段才能因论文破灭清仓"。

### 触发Tier1后补仓规则（仅A/E/F框架）

本规则仅适用于Tier1已实际卖出1/3建仓量的持仓；按Tier1「预设估值豁免」未卖出该份额的持仓（见上方"Tier 1：共享第一档"表格）不适用本规则——不存在"已卖出的1/3"可供补回。

同时满足以下全部条件时，可补回已卖出的1/3建仓量：
- 价格从Tier1止盈价回落 ≥12%
- L1/L2/L3核心逻辑完整未变（需按步骤2.5的方法论主动核查，逐条列出触发/未触发/待观察状态，不得仅凭印象判断"未变"；核查证据须与具体L3条件直接相关）
- 估值已回落至该框架的补仓阈值：A框架为PE_TTM低于近5年50%分位；E框架为按上方统一G口径计算的PEG `<1.5`（不使用未定义历史序列口径的"PEG近5年分位"）；F框架为PS低于近5年50%分位**且**收入增速未跌破15%（与步骤3 F科技卖出信号的双条件结构一致，不得只看PS）
- 右侧技术确认满足以下任一项（技术标准须可量化，避免"阳线企稳"这类未定义措辞）：①收盘价连续2个交易日站上20日均线；②最近一根已收盘周线的收盘价高于5周均线且高于前一周收盘价。仅出现盘中上穿、未连续2日收盘确认，或单根周阳线但收盘价仍低于5周均线，均不视为满足
- 按步骤0定义的可投资组合总资产计算股票总仓位<85%，且补仓后单股止损风险≤用户预算

上述估值和技术数据须为本次核查实时取得，并记录数据来源、as-of日期、具体数值及判定结果。任一指标缺失或口径无法确认时，不得判定补仓条件满足。实际补回已卖出份额并完成 `buy-holding` 后，必须显式执行 `$CACHE --confirm-write tier-update <代码> tier1 pending` 开启新的 Tier1 周期；Tier2/Tier3 状态保持不变，未复位前不得把新周期视为 Tier1 已完成。

禁止补仓：基本面有任何活动 `holding_deterioration` 黄色预警 / 下跌原因未查明 /
未提供总资产分母 / 股票总仓位已超85% / 补仓后风险预算超限

操作价格与可交易性以本轮 runtime 报价、时点和交易约束为准；报价缺失、过期或不可交易时，不得补造股数或成交。

> ⚠️ **历史分位极低须做反向解读检验**：分位越接近0，越可能有两种成因：①周期/情绪超跌（真便宜）；②行业ROE/盈利中枢结构性下移（历史均值基准已失效，不是便宜）。补仓前须在核查记录中明确排除后者（引用最新季报ROE趋势等信息），不得仅凭分位低直接判定"可以补仓"。
