# 完整投研执行流

仅在 `a-stock-cache check` 返回 `FULL_MISS`，或 `FUNDAMENTALS_HIT` 需要执行未缓存部分时读取。`ANALYSIS_HIT` 必须在主文件终止，不得加载本流程。主 `SKILL.md` 的行业/评分路由、`incomplete`、阈值、唯一动作出口、W1 和 QA 边界始终优先。

未确认具体写入时跳过 `set-analysis` 持久化，仍交付只读报告并按下一步执行 QA；不得因未写缓存而跳过 QA。

## 批量对比分析（多股票同时输入）

用户输入多个代码时（如「对比 600036 601288」或「分析 A、B、C」）：
1. 对每个代码分别串行执行 `a-stock-fetch fetch <股票代码>`，成功后再执行 `a-stock-cache check <股票代码>`；两个命令禁止并行
2. `ANALYSIS_HIT` 的直接复用缓存结论，无需 WebSearch
3. `FUNDAMENTALS_HIT` 只补搜异动、治理/政策与外部集中风险；B银行框架额外补搜净息差/不良率/拨备覆盖率
4. `FULL_MISS` 的执行完整分析流程
5. 全部完成后输出统一横向对比表格（参见[报告合同](report-contract.md)）

## 预筛选：格雷厄姆估值门槛（强制，在第零步之前执行）

先复用 runtime 中同口径的 EPS_TTM 与每股净资产；只对缺失、过期或冲突项补查正式披露，不重复搜索已有效的缓存字段。
计算：格雷厄姆数 = √(22.5 × EPS_TTM × 每股净资产)
买入参考价 = 格雷厄姆数 × 0.85

**EPS_TTM ≤ 0（亏损企业）**：跳过格雷厄姆数，标注"EPS为负，无格雷厄姆参考，改用框架主估值轴"，继续分析。

按主 `SKILL.md` 已确认的框架，只读取下方行业识别链接中的对应文件；其格雷厄姆分支与主估值轴用于本次预筛选及第三步择时评分，不加载其他框架。

## 第零步：异动检测 + 防韭菜预检（合并为单次搜索）

搜索：`[股票] [代码] 涨停 连板 异动 大股东减持 大宗交易 风险提示 最新`
> 搜索完成后立即提取两个信息点，各 1-2 句：
> ① **异动信号**：5日涨跌幅、是否涨停/连板、有无风险公告
> ② **减持/大宗信号**：有无大股东减持公告、大宗交易折价（有则标注，无则"无异常"）
> 不展开新闻正文。

若5日内涨停/连板，或3日涨幅>15%，标记为「异动股」：不终止分析，继续完整流程，但强制执行以下两条约束（在第三步择时评分中落地）：
①「市场情绪」分直接计 0 分，并按下方唯一计算顺序追加 -3 分；
② 时机评级最高只能给 ★（≤12/20）；该上限在双轨矩阵输出前统一应用，不再对矩阵结果二次乘比例。
结论首部置顶「⚠️ 近期异动，存在追高风险」；异动只影响上述择时参考评分，不单独把有效 Research 立场改为等待。

政策风险搜索：`[股票] [行业] 监管 政策 <当前年度> 最新`
> 搜索完成后立即提取：政策方向（支持/中性/压制）、主要事件（1条）。结论1句。

若搜索结果显示：行业处于政策压制期（限价/退出/整顿）→ 在结论首部置顶"⚠️ 政策逆风"警告，不终止分析但强调谨慎

## 第一步：行业识别

| 类型 | 判断依据 | 框架 |
|------|---------|------|
| 银行 | 仅商业银行 | B框架（NIM/不良率/拨备覆盖率） |
| 保险/券商 | 保险、券商、证券 | ⛔ 当前量化框架不适用——只输出定性摘要、关键指标及不适用说明，终止总分、时机评级和仓位矩阵；不得调用 `set-analysis` |
| 能源/资源 | 石油/煤炭/有色金属 | C框架 |
| 水电/公用 | 水电/电网/水务/燃气/高速 | D框架（类债券逻辑） |
| 消费 | 白酒/食品/零售 | E框架 |
| 科技/互联网 | 半导体/软件/AI/互联网平台/信创/新能源设备 | F框架 |
| 通用科技制造 | EMS/ODM/电子组装/连接器/线束/声学器件/元器件/精密电子制造 | A框架 |
| 亏损 Biotech | R&D支出/营收>40%，最近3个完整财年中≥2年净利润为负，主要价值来自管线/上市预期 | ⛔ 当前量化框架不适用——只输出管线阶段、现金跑道、关键临床/审批节点及失败风险的定性路线，终止总分、时机评级和仓位矩阵；不得调用 `set-analysis` |
| 公募REITs | 证券名称含"REIT"或"基础设施基金"，底层资产为不动产/基础设施 | ⛔ 本框架不适用——REITs底层为租金现金流而非企业利润，PE/ROE/格雷厄姆数均失效。输出：基本信息→拒绝原因→替代建议（股息率vs10年国债溢价+NAV折溢价，或参考中证指数REITs专项数据页）→终止评分 |
| 通用 | 其余行业 | A框架 |

**混合业务 tie-break 补充**：
- 创新药+仿制药混合（如恒瑞医药）：按最近财年主要营收口径占比>50%决定路由；若恰好50%，优先选A框架（保守处理）
- 其他混合业务：按主营业务占比最高者路由；无法判定时提示用户确认
- 主营收入占比 >50% 的业务决定框架；银行牌照持有方优先选 B，保险/券商/证券不得路由到 B
- 有水电/气/高速资产但以工业为主体 → 选 A，不选 D
- 科技制造按主营业务形态路由，不设毛利率硬门槛

确定框架后只读取对应文件：[A](frameworks/A.md)、[B](frameworks/B.md)、[C](frameworks/C.md)、[D](frameworks/D.md)、[E](frameworks/E.md)、[F](frameworks/F.md)。

## 第1.5步：周期位置判断（C/D/B框架必做，其余框架可选）

C/D/B 在评分前必须判断周期位置；C框架还必须核对关键动态变量、多业务段和分红压力。证据支持相邻阶段时，以更保守情景进入最终评级，不得包装成虚假单点精度。把主场景写入 `cycle_stage`；折扣顺序、压力测试和多业务段细则见[周期位置与压力测试细则](cycle-assessment.md)。

## 第二步：基本面评分（60分）

> **风险降级规则**：风险项触发时直接扣减对应维度得分，规则见各框架文件。

> **⚠️ 主观分项证据门槛**（适用所有框架的护城河/行业地位/特许经营稀缺性/品牌渠道类条目）：这类指标无客观数据可直接打分，容易凭印象/知名度给虚高分。打“强/优”档前必须列出至少1—2项可验证证据（如近3年提价但销量未下滑、客户流失率数据、市占率连续提升趋势、特许权剩余年限及续约历史）；缺乏证据时该维度最高只能打“中等/格”，不得仅凭公司知名度或主观印象判断。评分输入的 `subjective_assessments` 必须包含本框架映射后的两个判断：A/B 的护城河、C 的储量竞争力、F 的订单能见度/客户留存均映射为 `护城河`；D 映射为 `特许经营稀缺性`；E 映射为 `品牌渠道`；第二项均为 `行业地位`。每项携带 `category`、`rating`、`evidence`、`confidence`，枚举与完整性由 scorer 校验。报告可自然语言展示同一证据，但正文不是评分输入。

> **⚠️ A框架外部集中风险覆盖**：A框架每次都必须核验正式披露。未显示单一客户/地区高度集中或相关重大跨境限制时，记录“正常”及核验依据；存在集中敞口、限制、制裁、名单或未决实体裁决时，按证据判为“受限”或“重大”。将依据保留在报告和 decision-v1 的 `source_provenance`，不得依赖正文标签重建状态。“重大”不改60分结构，但配置分和配置级必须标注“置信度受限”，不得因满分或A级自动升级动作。最终动作仍只服从唯一操作出口（Research 立场为主干，见第四步）、异动、治理及组合约束，不另建第二出口。

> **⚠️ 客观分项核验门槛**：`checklist` 是事实锚点；简化判定只有补齐趋势/连续性正式证据后才能上调，未覆盖项仍须按框架文件收集证据，缺失不得包装成已核验。分档、折算、红线和周期叠加由 scorer 的版本化规则执行，禁止在报告中另写一套机器计分。

> **⚠️ 汇兑损益剔除规则**：若财务费用中汇兑损益导致当季/当年净利润出现重大扭曲（汇兑波动金额 > 该期净利润绝对值的30%），评估净利润增速时**必须计算同口径的经营性净利润增速**——即当期与对应基期均剔除汇兑损益后再计算增速，避免单边剔除导致比较基准失真；以同口径经营性增速作为框架净利增速维度打分的主要依据，表面净利润在报告中标注即可。（来源：2026-06-29 比亚迪Q1 2026 agy Critical审查；汇兑摆动约-40亿，表面-55.38%，同口径剔除后仅-14.7%）

**【客观核验】所有框架均执行**：执行 `a-stock-cache checklist <代码> <框架>`，将输出的核对清单作为本轮逐项打分的事实锚点，受上方"⚠️ 客观分项核验门槛"约束。清单中的 skipped 项仍按框架文档人工判断并保留原权重。若命令报错（非0退出码，如基本面缓存缺失）：停止基本面评分并报告缺口；不得再降级为纯人工加总。

**【确定性基本面评分】强制执行**：把缓存未提供但已从正式来源核验的指标放入 `metrics`，把上述主观判断放入 `subjective_assessments`；B/C/D 还须提供 `cycle_stage`，其他框架传 `null`。执行：

```bash
a-stock-cache score-fundamentals <代码> <框架A-F> '<评分输入JSON v1>'
```

评分输入 JSON v1 包含 `schema_version: 1`、`metrics`、`subjective_assessments`、`cycle_stage`：
- `metrics`：包含从正式公告补充的指标。A通用框架必须提供布尔值 `gross_margin_stable`。当 `check` 提示 `regulatory_incomplete` 且从交易所官方或公司年报核验确认无非标、无立案、非ST且分红达标时，可在 `metrics.regulatory_gate` 传入包含四大子门（`listing_risk`、`audit_opinion`、`investigation`、`dividend_compliance`）的完整 overrides 闭环 P0 门禁；对于处于扩产期且 ROE_TTM ≥ 15%、CAPEX/CFO ≤ 1.25 的高成长制造企业，可在 `metrics.a_capex_review` 传入资本开支复核（含 `capex_type`、`roe_ttm`、`expansion_rationale`、`sources`）解除 CAPEX 阻断；
- `subjective_assessments`：每项包含 `category`（如"护城河"、"行业地位"）、`rating`（"优档" 或 "格档"）、`confidence`（"高"、"中" 或 "低"）、`evidence`（非空字符串数组 `["可核验论据"]`）；
- `cycle_stage`：非 B/C/D 框架传 `null`；B/C/D 传对象 `{"stage": "...", "rationale": "..."}`。

具体枚举、必填项与评分规则由命令和 `a-stock-lib` 校验，不在 Skill 中复制。报告不得作为 stdin 或机器状态来源。命令输出的 `subtotal` 是唯一允许写入报告与 decision-v1 的基本面分；保留完整输出。`complete=false` 或 `blocked=true` 时停止配置评级、择时总分、综合分和仓位矩阵，只报告缺失输入或红线。禁止手工覆盖 subtotal，禁止在命令失败时退回自然语言加总。

## 第三步：择时评分（20分）

> 评分体系：基本面60分 + 择时20分（估值15分 + 市场情绪5分）= **总分80分**；技术信号为参考项，不计入总分，附在结论末尾。

**估值信号（15分）——以各框架主估值轴为准**

主估值轴、买入信号与次级参考见已加载的对应框架文件。

> **估值能力与确定性计分门槛**：A/E/F 使用近5年分位时，**不得用10年分位替代5年分位**；E/F 使用 PEG 时必须取得真实 TTM 盈利与可复核增长口径，缓存静态 `pe_static`（及 deprecated 兼容别名 `pe_ttm`）不得代替；F 使用 PS 时必须取得同口径近5年 PS 历史分位。满足对应框架已定义买入信号且证据完整时估值记15分；证据完整但未满足时**估值项记0/15**。所需5年分位、PS、真实PEG、报告期或交叉估值任一缺失/冲突时，估值项进入 `incomplete`，不得自创中间分，也不得输出时机评级、综合总分或仓位矩阵。

> 注：当主估值轴与格雷厄姆数结论冲突时，**主估值轴优先**，需在报告中明确说明冲突及裁决依据。

> ⚠️ **送转股/股本扩张不影响历史分位可比性**：10送X、10转X、资本公积转增等股本扩张后，行情软件历史PE分位均采用**后复权EPS+除权调整价格**自动重算，历史比较基准不失效。不应以"送转股导致历史基准不确定"为由对PE历史分位估值得分额外折扣。（来源：2026-06-29 比亚迪10送20 agy Critical审查）

> ⚠️ **历史分位极低时须做反向解读检验**：分位<5%时，存在两种解释：①历史均值回归（便宜）；②行业ROE/盈利中枢结构性下移（历史均值失去参考价值，不是便宜）。两种解释均与数据兼容时，**必须在报告中明确排除后者**（例如：引用最新季报ROE趋势、NIM企稳信号、行业政策环境），不得仅凭分位数低直接断言"历史低估"。（来源：2026-07-02 招商银行 agy Important审查）

**市场情绪（5分）**：只有融资余额状态和近期涨停/连板热度均有可核验时点、且均无极度亢奋信号时记5分；任一明确亢奋时记0分；任一数据缺失时择时项 `incomplete`，不得凭“未搜到异常”给5分。
> ⚠️ 第零步标记为「异动股」时：本项计 0 分，按唯一计算顺序追加 -3 分，时机评级上限强制为 ★（≤12/20）；不得在矩阵输出后再次减半，避免重复处罚和第二动作出口。

**预期差、除权/除息、市场风格与异动调整（必做/按条件触发）**：详细证据门、分级扣分和可证伪要求见[择时调整细则](timing-adjustments.md)。任一必需输入缺失时继续执行本节既有 `incomplete` 门，不得凭“未搜到异常”补分。

> **择时总分唯一计算顺序**：`raw = 估值分 + 市场情绪分 + 周期调整 + 预期差调整 + 除权/除息调整 + 市场风格调整 + 异动股调整`。周期调整仅顶部区为-3，其余阶段为0；异动股调整为-3；其他调整只取本节明确档位。先算 `bounded=max(0,min(20,raw))`，再应用 D框架溢价<150bps 的10分上限及异动股12分上限，得到最终择时分。任一必需输入 `incomplete` 时不计算 raw/总分，不得遗漏项目、重复扣分或改变顺序。

## 第四步：双轨参考评级与唯一动作

> 基本面分数反映"公司质地"，择时分数反映"买点质量"。两者独立且仅供参考；动作由有效 Research 立场与硬门禁决定，股数只取 `position-size`。

**配置评级**（基于基本面得分/60）：
| 得分 | 配置评级 | 含义 |
|------|---------|------|
| 50-60 | A级 | 质地参考优 |
| 40-49 | B级 | 质地参考良好 |
| 30-39 | C级 | 质地参考一般 |
| <30 | D级 | 质地参考较弱 |

**时机评级**（基于择时得分/20，含预期差调整）：
| 得分 | 时机评级 | 含义 |
|------|---------|------|
| 17-20 | ★★★ | 当前买点极佳 |
| 13-16 | ★★ | 买点尚可 |
| 9-12 | ★ | 择时参考一般 |
| <9 | — | 择时参考较弱 |

**双轨矩阵仅供参考**：展示 runtime 已校验的配置评级与时机评级，不再另列买入比例、等待或回避指令；评分缺失仍标 `not_formed`。实际动作和分批股数统一按下述出口。
